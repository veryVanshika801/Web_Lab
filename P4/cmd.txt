P4: GITHUB README AND VERSION TAGS
==================================

 
1. INTRODUCTION
---------------
GitHub is a website to store and share projects online. A README explains
the project, and version tags mark important versions of it.
 
 
2. WHAT IS A README?
--------------------
A README is a file named README.md in the main project folder. It is the
first thing people see on GitHub. It tells them what the project is and
how to use it.
 
Example:
 
    # My Project
    A simple to-do list app.
 
    ## How to run
    Open index.html in your browser.
 
 
3. WHAT ARE VERSION TAGS?
-------------------------
A version tag is a label for a specific point in the project, like a
bookmark. Example: v1.0 is the first finished version, v2.0 is a big update.
 
 
4. BASIC COMMANDS
-----------------
    git add README.md            Adds the file
    git commit -m "Add README"   Saves it with a message
    git push                     Uploads to GitHub
    git tag v1.0                 Creates the tag v1.0
    git push origin v1.0         Uploads the tag to GitHub
 
 
5. PRACTICAL EXAMPLE
--------------------
    Step 1:  Create README.md and write a title and description
    Step 2:  git add README.md
    Step 3:  git commit -m "Add README"
    Step 4:  git push
    Step 5:  git tag v1.0
    Step 6:  git push origin v1.0

 
 
6. CONCLUSION
-------------
A README helps people understand our project, and version tags help us
mark important versions. Together they keep a GitHub project clean and
professional.
